# DijkstraJava

[Case Study]
The High-Speed Rail project linking Kuala Lumpur and Singapore is a significant infrastructure project aimed at improving connectivity and reducing travel time between the two cities. The proposed route will connect major cities and towns in Malaysia and Singapore, including Kuala Lumpur, Seremban, Johor Bahru, and Singapore.

[Proposed Solution]
One of the suitable mathematical modeling approaches for this problem is graph
theory, a branch of discrete mathematics that deals with the study of graphs and networks.
Among the multiple algorithms, Dijkstra's algorithm is the most suitable for this problem because it is a single-source shortest path algorithm that can find the shortest path from a sole source to all other vertices in a graph with non-negative edge weights. The algorithm uses a priority queue data structure to find the shortest path efficiently

This Java program uses a dijkstra algorithm to calculate the shortest distance point a to point b. We have to manually input a distance from a node to the next node, Then this program computes the shortest distance from a point to the desired point of choice.
